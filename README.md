
# Movie Analysis Dashboard

An interactive movie analytics dashboard built using Python, Streamlit, Pandas, Matplotlib, Seaborn, and Plotly.

## Features
- Movie analytics KPIs
- Movies released per year
- Top 10 most popular movies
- Movie count by genre
- Average rating by genre
- Movie count by language
- Popularity vs. average rating analysis

## Tech Stack
- Python
- Streamlit
- Pandas and NumPy
- Matplotlib and Seaborn
- Plotly

## Installation

1. Clone this repository.
2. Install the required packages:

   pip install -r requirements.txt

3. Run the dashboard:

   streamlit run app.py

## Dataset
Place the required dataset in the project directory.
